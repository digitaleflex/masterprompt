# 4. Monitoring, Logs & Observabilité (Prompts 56-70)

*Focus : Détection d'incidents et réponse.*

## Prompt 56
Analyse la structure de mes logs. Sont-ils conformes au RGPD (anonymisation des IPs et emails) ?

## Prompt 57
Propose des alertes critiques basées sur le taux d'erreur 5xx et les tentatives de login échouées.

## Prompt 58
Comment centraliser les logs de sécurité pour qu'ils soient immuables (non modifiables par un attaquant) ?

## Prompt 59
Génère un tableau de bord Grafana pour surveiller les métriques de sécurité en temps réel (ex: tentatives d'injection SQL).

## Prompt 60
Implémente un système de tracing (OpenTelemetry) pour suivre une requête suspecte à travers tous les microservices.

## Prompt 61
Analyse les métriques de performance : comment détecter les anomalies qui pourraient indiquer une attaque ?

## Prompt 62
Comment implémenter un système de journalisation (audit trail) pour toutes les actions critiques ?

## Prompt 63
Vérifie si les logs contiennent des informations sensibles qui devraient être masquées.

## Prompt 64
Propose une stratégie de rotation et de rétention des logs conformes aux réglementations.

## Prompt 65
Comment configurer des alertes pour détecter les tentatives de brute force ?

## Prompt 66
Analyse les logs d'accès : comment détecter les accès suspects ou non autorisés ?

## Prompt 67
Comment implémenter un système de corrélation d'événements pour détecter des attaques complexes ?

## Prompt 68
Vérifie si les logs sont chiffrés pendant le transport et le stockage.

## Prompt 69
Comment surveiller les ressources système pour détecter des comportements anormaux ?

## Prompt 70
Analyse les logs réseau : comment détecter des communications suspectes vers l'extérieur ?
