# 5. Gouvernance & Compliance Code (Prompts 71-85)

*Focus : Standards de l'entreprise et législation.*

## Prompt 71
Vérifie si le code respecte les standards OWASP Top 10. Génère un rapport de conformité.

## Prompt 72
Ajoute des hooks de pré-commit pour forcer l'exécution de `npm audit` avant chaque push.

## Prompt 73
Comment automatiser la création d'un rapport de conformité pour un audit SOC2 ou ISO 27001 ?

## Prompt 74
Analyse si les données de santé ou bancaires sont chiffrées au repos (Encryption at Rest) dans ce schéma de base de données.

## Prompt 75
Propose une politique de rétention des données conforme au RGPD (suppression auto après X temps).

## Prompt 76
Analyse les politiques d'accès aux données : sont-elles conformes au principe du moindre privilège ?

## Prompt 77
Comment implémenter des revues de code obligatoires pour les modifications critiques ?

## Prompt 78
Vérifie si les documents de sécurité sont à jour et facilement accessibles aux développeurs.

## Prompt 79
Comment automatiser la vérification des licences open source dans le code ?

## Prompt 80
Analyse les processus de gestion des incidents : sont-ils documentés et testés régulièrement ?

## Prompt 81
Comment implémenter un système de gestion des vulnérabilités (Vulnerability Management) ?

## Prompt 82
Vérifie si les politiques de sécurité sont intégrées dans les outils de développement.

## Prompt 83
Comment automatiser la vérification des standards de codage (ex: via ESLint, SonarQube) ?

## Prompt 84
Analyse les processus de gestion des changements : sont-ils conformes aux bonnes pratiques ?

## Prompt 85
Comment implémenter une documentation de sécurité intégrée au code (ex: README de sécurité) ?
