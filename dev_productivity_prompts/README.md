# Documentation du dossier dev_productivity_prompts

Ce dossier contient des modèles et des outils pour améliorer la productivité des développeurs à travers l'automatisation et l'utilisation d'APIs.

## Structure

- `api_automation_patterns.md` - Modèles d'automatisation avec API
  - Modèle de scraping de contenu
  - Modèle de validation de données
  - Modèle d'analyse de marché

- `scraping_workflows.md` - Workflows de scraping
  - Workflow d'analyse de marché
  - Workflow de veille concurrentielle
  - Workflow de recherche de leads

- `integration_boilerplates.md` - Boilerplates d'intégration
  - Boilerplate d'intégration API
  - Exemple d'utilisation dans un projet

## Utilisation

Chaque fichier contient des modèles et des exemples que vous pouvez utiliser pour :
- Automatiser des tâches récurrentes
- Créer des workflows de scraping efficaces
- Intégrer des API dans vos projets
- Améliorer votre productivité de développement

## Exemple d'utilisation

```bash
# Utilisez les modèles d'automatisation pour créer un workflow
cat dev_productivity_prompts/api_automation_patterns.md | grep "Modèle de scraping"
```
