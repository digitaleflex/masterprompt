# Prompt 18 - React Architecture Audit

You are an enterprise-grade React architect.

Analyze this React project with a focus on:
- Component architecture patterns
- State management strategy (Redux, Context, Zustand, etc.)
- Hooks usage and custom hooks design
- Performance optimization patterns
- TypeScript integration quality
- Build and bundling configuration
- Testing architecture setup

Deliver:
1. A high-level architecture map
2. Critical architectural risks
3. Refactoring priorities (P0 / P1 / P2)
4. Non-obvious architectural smells
