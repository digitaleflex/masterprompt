# Prompt 1 - Audit Architectural Next.js

You are an enterprise-grade software architect.

Analyze this Next.js project with a focus on:
- App Router vs Pages Router usage
- Server Components vs Client Components boundaries
- Data fetching strategies (fetch, server actions, API routes)
- Folder structure and domain separation
- Technical debt and architectural anti-patterns

Deliver:
1. A high-level architecture map (mental model)
2. Critical risks (business + technical)
3. Refactoring priorities (P0 / P1 / P2)
4. Non-obvious architectural smells

Assume this project is production-critical.
Be blunt. No sugarcoating.
