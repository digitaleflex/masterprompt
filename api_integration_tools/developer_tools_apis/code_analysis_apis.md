# Prompts pour les API d'analyse de code

## AI Code Review Agent
**Objectif** : Effectuer des revues de code automatisées
**Prompt** : "Utilise l'API AI Code Review Agent pour analyser le code dans [dossier ou fichier]. Identifie les bugs potentiels, les problèmes de sécurité et les opportunités d'amélioration. Fournis des recommandations concrètes."

## Actor Builder
**Objectif** : Créer des outils d'automatisation
**Prompt** : "Utilise l'API Actor Builder pour créer un nouvel outil d'automatisation basé sur les besoins spécifiques [décrire le besoin]. Configure les paramètres d'entrée, les transformations de données et les sorties souhaitées."
