# Prompts pour les API de recherche

## GPT Search [Private API]
**Objectif** : Effectuer des recherches avancées avec GPT
**Prompt** : "Utilise l'API GPT Search pour effectuer une recherche approfondie sur [sujet]. Fournis une synthèse structurée avec des sources vérifiables et des recommandations basées sur les dernières informations disponibles."

## Bing Copilot [API]
**Objectif** : Utiliser Bing Copilot pour des informations en temps réel
**Prompt** : "Utilise l'API Bing Copilot pour obtenir des informations en temps réel sur [sujet]. Compare avec d'autres sources et fournis une analyse approfondie avec des liens vers les sources originales."
