# Guidelines de Contribution

Merci de contribuer à MasterPrompt ! Voici quelques lignes directrices pour vous aider à contribuer efficacement.

## 🛠 Prérequis

Avant de contribuer, assurez-vous d'avoir :

- Git installé
- Node.js (version 16 ou supérieure)
- Un compte GitHub

## 🔄 Processus de contribution

1. **Fork** le dépôt
2. **Clone** votre fork
   ```bash
   git clone https://github.com/VOTRE_USERNAME/masterprompt.git
   ```
3. **Créez une branche** pour votre feature
   ```bash
   git checkout -b feature/NomDeVotreFeature
   ```
4. **Faites vos modifications**
5. **Commit** vos changements
   ```bash
   git commit -m 'Ajoute une nouvelle feature'
   ```
6. **Poussez** sur la branche
   ```bash
   git push origin feature/NomDeVotreFeature
   ```
7. **Ouvrez une Pull Request**

## 📝 Règles de contribution

### Code de conduite
Veuillez suivre notre [Code de conduite](CODE_OF_CONDUCT.md) dans toutes vos interactions.

### Style de codage
- Suivez les conventions de nommage existantes
- Ajoutez des commentaires pertinents
- Écrivez des tests pour les nouvelles fonctionnalités
- Assurez-vous que les tests existants passent

### Structure des commits
Utilisez le format suivant pour vos messages de commit :
```
type(scope): description

feat: nouvelle fonctionnalité
fix: correction de bug
docs: documentation
style: formatage, style
refactor: refactorisation de code
test: ajout de tests
chore: tâches de maintenance
```

## 🚀 Bonnes premières issues

Recherchez les issues marquées avec le label `good-first-issue` si vous cherchez une bonne première contribution.

## ❓ Besoin d'aide ?

Si vous avez des questions, n'hésitez pas à :
- Ouvrir une issue
- Consulter la documentation
- Rejoindre la discussion sur les PRs existantes

## 🎯 Domaines de contribution

Nous recherchons des contributions dans les domaines suivants :
- Documentation
- Tests
- Nouvelles fonctionnalités
- Corrections de bugs
- Amélioration de la qualité du code
- Sécurité
- Intégration d'APIs

Merci de votre intérêt pour ce projet ! ❤️
